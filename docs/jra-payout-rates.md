# JRA払戻率の実装根拠

JRA公式「馬券のルール」では、設定払戻率を単勝80.00%、複勝80.00%、枠連77.50%、馬連77.50%、ワイド77.50%、馬単75.00%、3連複75.00%、3連単72.50%、WIN5 70.00%として掲載している。アプリでは今回対象の単勝・馬連・ワイド・三連複に、それぞれ0.800、0.775、0.775、0.750を初期値として使用する。

JRA公式は払戻対象総額の計算式として「(W + D/P) × R（WIN5のみ + A/P）」を掲載している。今回のブラウザ内分析は入力された最終オッズとモデル確率の比較を目的とするため、簡易な券種別払戻率補正を適用し、実際の発売票数・同着・返還・税等は扱わない旨を画面に明記する。
